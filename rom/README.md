# rom/

Put **your own** disc image of *Star Fox Assault* (USA, disc ID `GF7E01`) here as an
uncompressed `.iso` or a `.ciso`, e.g. `rom/game.iso`.

Everything in this directory except this README is ignored by git. Never commit, upload
or link to game images, in issues or pull requests either. See the top-level
[README](../README.md) for how to dump your own disc and convert other formats.
